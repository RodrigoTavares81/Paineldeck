# Capas dos jogos

As capas são a arte oficial de cada jogo, então ficam só no seu PC e não vão pro repositório.

Coloque aqui as imagens que o `deck.json` aponta em `games[].image` (por exemplo `games/arc-raiders.jpg`).
Capa em pé (2:3) preenche o card; logo quadrado ou deitado aparece inteiro sobre um fundo desfocado.
Sem imagem, o card mostra a inicial do jogo.

Onde achar:
- Steam: `C:\Program Files (x86)\Steam\appcache\librarycache\<appid>\...\library_600x900.jpg`
- Ubisoft Connect: cache do launcher em `Ubisoft Game Launcher\cache`
- Xbox/Microsoft Store: pasta `Resources` do pacote em `C:\Program Files\WindowsApps`
